プライバシーポリシー

「手話 区域訪問記録 本人確認」（以下「このアプリ」）での情報の取り扱いについて説明します。

受け取る情報

Google アカウントでログインした人のメールアドレスだけを受け取ります。名前・連絡先・写真など、ほかの情報は受け取りません。

使い道

受け取ったメールアドレスは、区域訪問記録アプリを使ってよい人（管理者が登録した利用者）かどうかを確かめるためだけに使います。

保存について

  • このアプリは、メールアドレスを保存しません
  • 確かめた印（通行証）は、利用者の端末のブラウザに90日間だけ保存されます。「ログアウト」を押すと消えます
  • 区域訪問記録アプリは、通行証のメールアドレスを、管理者が登録した利用者の一覧と照らし合わせるだけです

ほかの人や会社に渡すこと

受け取った情報を、ほかの人や会社に渡したり、売ったり、広告に使ったりすることはありません。

このアプリが Google から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（Google API Services User Data Policy）の「限定的な使用」の要件を含めて、そのポリシーに従います。

許可の取り消し

このアプリへの許可は、Google アカウントの設定（サードパーティ製のアプリとサービス）からいつでも取り消せます。

お問い合わせ

このポリシーについてのお問い合わせは、区域の管理者にお願いします。
